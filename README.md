# Albero filogenetico degli LLM

Visualizzazione interattiva (D3.js) di 57 modelli linguistici, open e chiusi: da quale modello deriva ciascuno, quali distillazioni collegano famiglie diverse, quanta VRAM richiede rispetto alla GPU scelta e come si comporta su tre task (LMArena).

Progetto per l'esame di Data Visualization. Apri la demo da `web/index.html`, servita da un server statico (per esempio GitHub Pages o `python3 -m http.server`).

Dati: Epoch AI (CC-BY 4.0), Hugging Face, LMArena, paper tecnici; ogni valore riporta la sua fonte nel tooltip.
